# Contributing · المساهمة

Bug reports, ideas and pull requests are welcome.

- **Found a bug or a wrong number?** Open an issue with the command you ran, what you expected and what you got.
- **Want to add something?** Open an issue first so we can agree on the shape, then send a pull request.
- **Tests:** `python3 -m unittest discover -s tests -v` must pass. Add a test for anything you change.
- **Rules that do not change:** standard-library Python only, no exchange or broker connection, no order placement, no API keys.

البلاغات والاقتراحات وطلبات الدمج مرحب بيها. افتح Issue واشرح المشكلة أو الفكرة، وتأكد إن الاختبارات تعبر قبل ما تدز تعديل.
